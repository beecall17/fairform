# fairform

## FairForm Project Structure

### Directory Layout
- `src/agents/` - Five agent implementations
- `src/models/` - Credit model (XGBoost) 
- `src/data/` - Data loading and processing
- `src/experiments/` - Experiment scripts (1-6)
- `src/utils/` - Helper functions
- `notebooks/` - Jupyter notebooks for exploration
- `configs/` - YAML configs (rules, model params)
- `data/raw/` - HMDA raw data
- `data/processed/` - Cleaned HMDA
- `data/synthetic/` - Generated forms
- `reports/` - Generated compliance reports
- `papers/` - Paper drafts and figures
